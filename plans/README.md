# plans/

Written **before** building. One file per feature/change, named `<slug>.md`.

- `ROADMAP.md` — what's left, by priority (keep current).
- `BACKLOG.md` — deferred ideas, with reasons and triggers.
- `NNNN-<slug>.md` — a plan (see [`../templates/plan.md.template`](../templates/plan.md.template)).

A plan is the agreement you and the agent make before code exists. Write it, then
**stop and wait for approval**. See [`../docs/02-planning.md`](../docs/02-planning.md).
