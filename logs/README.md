# logs/

Written **after** the work. One file per task, named `YYYY-MM-DD_<slug>.md`.

A log records what actually happened: the **root cause**, what changed, and how it was
**verified**. It's the audit trail that lets a future reader (or AI model) reconstruct
the reasoning without the chat. See [`../docs/04-logging.md`](../docs/04-logging.md)
and [`../templates/log.md.template`](../templates/log.md.template).
